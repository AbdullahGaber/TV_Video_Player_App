# Video Assets

Place your video files in this directory.

## Supported Formats
- MP4
- MOV
- AVI
- MKV

## Sample Videos
For testing, you can download sample videos from:
- https://sample-videos.com/
- https://test-videos.co.uk/

## Instructions
1. Add your video files to this folder
2. The app will automatically detect and play them
3. Recommended: Use MP4 format for best compatibility with Android TVs

## Example
Place a file named `sample.mp4` in this directory and the app will play it automatically.
